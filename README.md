### 🏋️‍♂️ Overview
**IronPulse** is a full-stack fitness management application designed to streamline the bodybuilding journey. Whether you're tracking macros or logging heavy sets, this platform provides a clean, "Dark Mode" aesthetic interface to keep athletes focused on their gains.

### 🛠️ Tech Stack
| Category | Technology |
| :--- | :--- |
| **Frontend** | React.js / Next.js |
| **Backend** | Node.js / Express |
| **Database** | MongoDB / MySQL |
| **State Management** | Redux Toolkit |
| **Styling** | Tailwind CSS / Material UI |

### ✨ Key Features
*   **Workout Logger:** Create and save custom workout routines with set/rep tracking.
*   **Progress Dashboard:** Visual charts to monitor muscle growth and weight fluctuations.
*   **Nutrition Tracker:** Integrated search for tracking daily calorie and protein intake.
*   **Exercise Library:** A curated list of exercises with proper form descriptions and animations.
*   **Personalized Profile:** User-specific dashboard showing personal bests (PBs) and consistency streaks.
